groupBy() Polyfill in JavaScript

Write a polyfill for groupBy() that groups elements of a collection based on a key derived from either a function or a property name. This is a classic interview question testing reduce, higher-order functions, and data transformation.

Difficulty: ⭐⭐ Category: Data Transformation Frequency: High #polyfill #groupBy #reduce #interview

The question

Restate what the interviewer is really asking before you write code.

  • Group array elements by a key derived from a function or property name.
  • Return an object where keys are group identifiers and values are arrays of elements.
  • Handle both groupBy(arr, fn) and groupBy(arr, "prop").
Input
groupBy([6.1, 4.2, 6.3], Math.floor)
groupBy(["one","two","three"], "length")
Output
{ 6: [6.1, 6.3], 4: [4.2] }
{ 3: ["one","two"], 5: ["three"] }

How the question is asked

A

Direct polyfill request

"Write a polyfill for Object.groupBy() or lodash's _.groupBy()."

The interviewer wants to see you handle dynamic iteratees (function vs. property string) and build the grouping with reduce().

B

Progressive complexity

"Group by a function." → "Now by a property name." → "Handle both in one function." → "What about ES2023?"

How to answer, step by step

1

Clarify the question

"Should the iteratee be a function, a property name string, or both? And should the result be an object or a Map?"

2

Handle the dynamic iteratee

"The key insight is detecting whether the iteratee is a function or a string, then computing the key accordingly."

// Function iteratee: apply it to the element
const key = keyFinder(element);  // e.g., Math.floor(6.1) → 6

// Property iteratee: access the property
const key = element[keyFinder];  // e.g., "one".length → 3

// Unified:
const key = typeof keyFinder === 'function'
  ? keyFinder(b)
  : b[keyFinder];
3

Write the full implementation

const groupBy = (values, keyFinder) => {
  return values.reduce((a, b) => {
    const key = typeof keyFinder === 'function'
      ? keyFinder(b)
      : b[keyFinder];

    if (!a[key]) {
      a[key] = [b];
    } else {
      a[key] = [...a[key], b];
    }

    return a;
  }, {});
};
Test it
console.log(groupBy([6.1, 4.2, 6.3], Math.floor));
// { 6: [6.1, 6.3], 4: [4.2] }

console.log(groupBy(["one", "two", "three"], "length"));
// { 3: ["one", "two"], 5: ["three"] }

// ES2023 native version:
const result = Object.groupBy(["one", "two", "three"], (s) => s.length);
// { 3: ["one", "two"], 5: ["three"] }
4

Close with edge cases

✓ Performance optimization
// Instead of spreading (creates new array each time):
a[key] = [...a[key], b];

// Use push (mutates in place, faster for large datasets):
a[key].push(b);
ⓘ Time & space complexity
  • Time: O(n) single pass through the array.
  • Space: O(n) for the result object and grouped arrays.
⚠ ES2023 availability

Object.groupBy() is available in modern engines but not everywhere. The polyfill is useful for older environments and for understanding the mechanics.

Key insights

  • Dynamic iteratees (function or property) make groupBy flexible and reusable.
  • reduce() provides an elegant one-pass aggregation into an object.
  • Mirrors functionality from Lodash _.groupBy and ES2023 Object.groupBy().
  • For large datasets, prefer push() over spread for performance.
  • Demonstrates higher-order function usage and object aggregation via reduce.
  • A common interview favorite and a real-world utility for data transformation.

Takeaway
