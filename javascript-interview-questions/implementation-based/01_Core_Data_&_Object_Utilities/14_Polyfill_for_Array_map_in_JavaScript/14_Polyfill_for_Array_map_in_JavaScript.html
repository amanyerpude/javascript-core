Polyfill for Array.map() in JavaScript

Implement Array.prototype.map() from scratch. This is an extremely common interview question that tests your understanding of closures, higher-order functions, prototype extension, and edge case handling.

Difficulty: ⭐⭐ Category: Prototype & Polyfills Frequency: Very High #polyfill #map #array #prototype #interview

The question

Restate what the interviewer is really asking before you write code.

  • Implement Array.prototype.map() that takes a callback and returns a new array.
  • The callback receives (element, index, array).
  • The original array must not be mutated.
Input
[1, 2, 3].map((e) => e * 2)
Output
[2, 4, 6]

How to answer, step by step

1

Clarify the question

"Should I handle sparse arrays, the thisArg parameter, and type checking for the callback?"

2

Explain the callback arguments

// Native map calls the callback like this:
callback(element, index, originalArray)

// Example:
[1, 2, 3].map((num, index, arr) => {
  console.log(num, index, arr);
  return num * 2;
});
// 1 0 [1,2,3]
// 2 1 [1,2,3]
// 3 2 [1,2,3]
3

Write the basic polyfill

Array.prototype.map = function (callback) {
  const result = [];

  for (let i = 0; i < this.length; i++) {
    if (this.indexOf(this[i]) > -1) {
      result[i] = callback(this[i], i, this);
    }
  }

  return result;
};
4

Write the robust version

Array.prototype.map = function (callback, thisArg) {
  if (typeof callback !== "function") {
    throw new TypeError(callback + " is not a function");
  }

  const result = new Array(this.length);

  for (let i = 0; i < this.length; i++) {
    if (i in this) {
      result[i] = callback.call(thisArg, this[i], i, this);
    }
  }

  return result;
};
Line-by-line breakdown

Line 1: Takes a callback and optional thisArg for context binding.

Line 2: Throws TypeError if callback is not a function.

Line 3: new Array(this.length) pre-allocates, preserving sparse slots.

Line 5: i in this skips empty slots in sparse arrays.

Line 6: callback.call(thisArg, ...) binds context and passes all three arguments.

Test it
const arr = [1, 2, 3];
const doubled = arr.map((num, index, original) => {
  console.log(`Index: ${index}`);
  return num * 2;
});
console.log(doubled); // [2, 4, 6]
5

Close with edge cases

✓ Sparse arrays
const sparse = [1, , 3];
const result = sparse.map((e) => e * 2);
console.log(result); // [2, empty, 6]
ⓘ Non-mutating

map() always returns a new array. The original is never modified.

ⓘ Time & space complexity
  • Time: O(n) where n is the array length.
  • Space: O(n) for the new result array.

Key insights

  • map() is non-mutating — it creates a new array.
  • The callback receives three arguments: element, index, and the original array.
  • Sparse array handling — i in this skips holes.
  • thisArg binds the callback's this context.
  • Type checking the callback matches native TypeError behavior.
  • Writing a polyfill forces you to understand array traversal, callback invocation, and context binding.

Takeaway

Implementing a map() polyfill covers closures & higher-order functions, prototype extension, and edge case handling (thisArg, sparse arrays). This is a classic interview problem and an essential step to mastering JavaScript internals.
