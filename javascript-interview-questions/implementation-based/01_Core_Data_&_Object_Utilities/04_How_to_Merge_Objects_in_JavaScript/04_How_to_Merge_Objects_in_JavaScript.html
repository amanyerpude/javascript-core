How to Merge Objects in JavaScript

Almost everything in JavaScript is an object, yet JS didn't originally have built-in methods for merging them. This question tests your knowledge of shallow vs. deep merging, spread syntax, Object.assign, and custom recursive implementations.

Difficulty: ⭐⭐ Category: Object Operations Frequency: High #object #merge #shallow #deep #spread

The question

Restate what the interviewer is really asking before you write code.

  • Merge two or more objects into one.
  • Understand the difference between shallow merge (top-level only) and deep merge (recursive).
  • Be ready to discuss spread syntax, Object.assign, and write custom polyfills for both.
Input
obj1 = { name: "prashant", age: 23,
         nature: { helping: true, shy: false } }

obj2 = { qualification: "BSC CS",
         nature: { angry: false, shy: true } }
Output (deep merge)
{
  name: "prashant",
  age: 23,
  qualification: "BSC CS",
  nature: { helping: true, angry: false, shy: true }
}

How the question is asked

The same problem can enter from different doors. Recognise the entry point and pick the right approach.

A

Shallow merge request

"How do you merge two objects in JavaScript?"

The interviewer wants to see if you know the built-in tools first. Start with spread syntax and Object.assign, then mention the custom implementation.

What to do: Show spread first (most idiomatic), then Object.assign, then a custom function. Explain that both are shallow — nested objects are not deeply merged.

B

Deep merge request

"What about nested objects? How do you deeply merge?"

The interviewer is probing deeper. They want to see recursion and type checking. This is where the real implementation challenge lies.

What to do: Explain that shallow merge overwrites nested objects entirely. Then write a recursive deep merge function using Object.prototype.toString.call() or typeof + Object.keys().

Shallow
// Spread overwrites nested objects
{ ...obj1, ...obj2 }
// nature: { angry: false, shy: true }
// helping: true is LOST!
Deep
// Recursive merge preserves both
merge(true, obj1, obj2)
// nature: { helping: true, angry: false, shy: true }
// helping: true is PRESERVED

How to answer, step by step

Regardless of how the question is asked, the strongest answer follows this progression.

1

Clarify the question

"Should I do a shallow merge or a deep merge? With a shallow merge, nested objects are overwritten entirely. With a deep merge, nested objects are recursively combined."

This shows you understand the critical distinction before writing any code. The interviewer will almost always say "deep merge" — but starting with shallow shows breadth.

2

Show the native approaches

"For shallow merges, JavaScript gives us two built-in tools: spread syntax and Object.assign."

A. Spread operator
let obj1 = { name: 'prashant', age: 23 };
let obj2 = { qualification: 'BSC CS', loves: 'Javascript' };

let merge = { ...obj1, ...obj2 };

console.log(merge);
// { name: "prashant", age: 23, qualification: "BSC CS", loves: "Javascript" }

Spread copies all enumerable own properties into a new object. The rightmost object wins on duplicate keys.

B. Object.assign
let merge = Object.assign({}, obj1, obj2);

console.log(merge);
// { name: "prashant", age: 23, qualification: "BSC CS", loves: "Javascript" }
ⓘ Why pass an empty object?

Object.assign({}, obj1, obj2) — the empty {} as the first argument ensures you don't mutate the original objects. Without it, you'd modify obj1 directly.

Both are shallow. If obj1.nature = { helping: true } and obj2.nature = { shy: true }, the result has nature: { shy: true } — the nested object from obj1 is completely overwritten.

3

Write a custom shallow merge

"Here's how you'd implement shallow merge from scratch — useful if you need to understand what's happening under the hood."

let merge = (...arguments) => {
  let target = {};

  let merger = (obj) => {
    for (let prop in obj) {
      if (obj.hasOwnProperty(prop)) {
        target[prop] = obj[prop];
      }
    }
  };

  for (let i = 0; i < arguments.length; i++) {
    merger(arguments[i]);
  }

  return target;
};
✓ Key detail

Using for...in with hasOwnProperty ensures we only copy own properties, not inherited ones from the prototype chain. This matches the behavior of Object.assign.

4

Write the deep merge function

"Now for the real challenge — a recursive deep merge that combines nested objects instead of overwriting them."

A. Pseudocode
function merge(...args):
    create empty target object

    for each source object:
        for each property in source:
            if property value is an object (not null, not array):
                recursively merge target[prop] and source[prop]
            else:
                copy source[prop] to target[prop]

    return target
B. The implementation
let merge = (...arguments) => {
  let target = {};

  let merger = (obj) => {
    for (let prop in obj) {
      if (obj.hasOwnProperty(prop)) {
        if (Object.prototype.toString.call(obj[prop]) === '[object Object]') {
          target[prop] = merge(target[prop], obj[prop]);
        } else {
          target[prop] = obj[prop];
        }
      }
    }
  };

  for (let i = 0; i < arguments.length; i++) {
    merger(arguments[i]);
  }

  return target;
};
C. Test it
let obj1 = {
  name: 'prashant',
  age: 23,
  nature: { "helping": true, "shy": false }
};

let obj2 = {
  qualification: 'BSC CS',
  loves: 'Javascript',
  nature: { "angry": false, "shy": true }
};

console.log(merge(obj1, obj2));
// {
//   name: "prashant",
//   age: 23,
//   qualification: "BSC CS",
//   loves: "Javascript",
//   nature: { helping: true, angry: false, shy: true }
// }
ⓘ Type checking choice

Object.prototype.toString.call(obj[prop]) === '[object Object]' is the most reliable way to check for plain objects. typeof returns "object" for both objects and arrays, and null also has typeof "object". The toString check avoids these pitfalls.

5

Write the unified function (shallow + deep)

"We can combine both into a single function — if the first argument is true, it does a deep merge. Otherwise, shallow."

let merge = (...arguments) => {
   let target = {};
   let deep = false;
   let i = 0;

   if (typeof (arguments[0]) === 'boolean') {
      deep = arguments[0];
      i++;
   }

   let merger = (obj) => {
    for (let prop in obj) {
      if (obj.hasOwnProperty(prop)) {
        if (deep && Object.prototype.toString.call(obj[prop]) === '[object Object]') {
          target[prop] = merge(target[prop], obj[prop]);
        } else {
          target[prop] = obj[prop];
        }
      }
    }
   };

   for (; i < arguments.length; i++) {
    merger(arguments[i]);
   }

   return target;
};
Shallow call
merge(obj1, obj2)
// nature: { angry: false, shy: true }
// helping: true is LOST (shallow)
Deep call
merge(true, obj1, obj2)
// nature: { helping: true, angry: false, shy: true }
// helping: true is PRESERVED (deep)
6

Close with edge cases and complexity

"A few edge cases — arrays, null values, circular references, and property order. Time complexity is O(n) where n is the total number of properties across all nesting levels."

✓ Arrays

Our deep merge only handles plain objects. Arrays would be overwritten, not merged. You'd need additional logic to handle array merging (concat, union, etc.).

✓ Null values
// null has typeof "object" in JS, but toString gives "[object Null]"
// Our check: toString === '[object Object]' safely skips null
merge({ a: 1 }, { a: null });
// { a: null }  — null overwrites 1, which is correct
⚠ Circular references

If an object references itself, the recursive merge will loop infinitely:

const a = { x: 1 };
a.self = a;
merge(a, { y: 2 });  // RangeError!

In production, you'd track visited objects. Mention this proactively.

ⓘ Time & space complexity
  • Time: O(n) where n is the total number of properties across all nesting levels. Every property is visited exactly once.
  • Space: O(n) for the result object, plus O(d) for the call stack where d is the maximum nesting depth.
⚠ Production libraries

In production, consider using Lodash (_.merge()) or jQuery ($.extend()). They handle edge cases, arrays, circular references, and have been battle-tested across millions of projects.

Key insights

  • Shallow vs. deep is the fundamental distinction — always clarify which one the interviewer wants.
  • Spread and Object.assign are identical in behavior — both shallow. Spread is more idiomatic in modern JS.
  • Always pass {} as the target in Object.assign to avoid mutating the original objects.
  • Deep merge requires recursion and type checking — Object.prototype.toString.call() is the most reliable check.
  • The unified function (shallow + deep) is a clean interview flex that shows design thinking.
  • Mention libraries (Lodash, jQuery) for production — it shows practical judgment, not just algorithmic skill.
  • Edge cases (arrays, null, circular refs) are what separate a good answer from a great one.

Takeaway

Merging objects is a common real-world need — from config handling to API responses. Use spread or Object.assign for quick shallow merges. Use custom recursion for deep merging without external libraries. In production, rely on Lodash or jQuery for battle-tested solutions. Knowing both approaches (and when to use them) is an essential JavaScript skill.
