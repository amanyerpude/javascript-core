Aggregate Array of Objects on Given Keys

Given an array of objects and two keys on and who, aggregate the who values based on the on values. This is a common data transformation problem that tests your mastery of reduce() and object manipulation.

Difficulty: ⭐⭐ Category: Data Transformation Frequency: Medium #aggregate #reduce #array #groupBy

The question

Restate what the interviewer is really asking before you write code.

  • Group an array of objects by one key, aggregating values from another key.
  • Return an array of grouped objects.
  • This is essentially a groupBy operation using reduce().
Input
[
  { skill: 'css', user: 'Bill' },
  { skill: 'js', user: 'Chad' },
  { skill: 'js', user: 'Bill' },
  { skill: 'css', user: 'Sue' }
]
aggregate(arr, "user", "skill")
Output
[
  { user: "Bill", skill: ["css","js"] },
  { user: "Chad", skill: ["js"] },
  { user: "Sue",  skill: ["css"] }
]

How the question is asked

A

Group by key request

"Given this array, group the users by their skills."

The interviewer gives you data and asks for grouping. Start by clarifying: should the result be an object or an array? What about duplicates?

B

Progressive complexity

"Group by skill." → "Now group by user." → "What about duplicates?" → "Can you make it generic?"

The interviewer wants you to build a flexible, reusable function.

How to answer, step by step

1

Clarify the question

"Should the output be an array of objects or a plain object? And should I deduplicate the aggregated values?"

2

Explain the reduce strategy

"I'll use reduce() to build a grouping map, then return its values."

// Algorithm:
// 1. Loop over the input array with reduce
// 2. For each element, get the "on" value (grouping key) and "who" value
// 3. If the group already exists → append to its array
// 4. If not → create a new entry
// 5. Return Object.values() to convert the map to an array
3

Write the full implementation

const aggregate = (arr, on, who) => {
  const agg = arr.reduce((a, b) => {
    const onValue = b[on];
    const whoValue = b[who];

    if (a[onValue]) {
      a[onValue] = {
        [on]: onValue,
        [who]: [...a[onValue][who], whoValue]
      };
    } else {
      a[onValue] = {
        [on]: onValue,
        [who]: [whoValue]
      };
    }

    return a;
  }, {});

  return Object.values(agg);
};
Test it

  { skill: 'javascript', user: 'Sue' },

4

Close with edge cases

✓ Deduplication
// If duplicates need to be removed:
[who]: [...new Set([...a[onValue][who], whoValue])]
ⓘ Time & space complexity
  • Time: O(n) single pass through the array.
  • Space: O(n) for the accumulator and result.
⚠ Mutating the accumulator

The spread operator [...a[onValue][who], whoValue] creates a new array each time. This is safe — we're not mutating the previous array.

Key insights

  • This is essentially a groupBy operation, aggregating values by a chosen key.
  • reduce() is the natural fit for single-pass transformations.
  • Flexible: you can aggregate on any property (votes by candidate, sales by region, etc.).
  • Object.values() converts the grouping map back to an array.
  • For deduplication, wrap with new Set().
  • This tests knowledge of reduce(), objects, and array transformations — a common interview question.

Takeaway

Using reduce() to aggregate arrays is a powerful pattern. It creates maps of grouped data, transforms data into reporting formats, and is reusable by swapping keys to pivot the grouping logic. This is a common interview question because it tests reduce(), objects, and array transformations.
