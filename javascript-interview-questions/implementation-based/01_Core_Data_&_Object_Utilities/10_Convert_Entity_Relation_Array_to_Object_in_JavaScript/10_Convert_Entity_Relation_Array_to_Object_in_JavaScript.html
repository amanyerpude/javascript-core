JavaScript Interview · Implementation Question

Convert Entity-Relation Array to Object

Given an array of [child, parent] pairs, convert it into an ancestry chain expressed as strings like "animal -> mammal -> cat -> lion". This tests reduce, recursion, and graph traversal.

Difficulty: ⭐⭐⭐ Category: Graph & Recursion Frequency: Medium #relations #tree #reduce #recursion

The question

Restate what the interviewer is really asking before you write code.

  • Input: array of [child, parent] pairs in random order.
  • Output: array of strings showing full ancestry chains from root to leaf.
  • Each node should appear in its own chain (e.g., "animal -> mammal" and "animal -> mammal -> cat").
Input
[["lion","cat"], ["cat","mammal"],
 ["dog","mammal"], ["mammal","animal"],
 ["fish","animal"], ["shark","fish"]]
Output
["animal -> mammal -> cat -> lion",
 "animal -> mammal -> cat",
 "animal -> mammal -> dog",
 "animal -> mammal",
 "animal -> fish",
 "animal -> fish -> shark"]

How the question is asked

A

Direct conversion request

"Given these parent-child pairs, build the full ancestry tree as strings."

This tests your ability to combine reduce() for aggregation with recursion for tree traversal.

B

Progressive complexity

"Convert to a map." → "Now build ancestry strings." → "Handle multiple roots." → "What about cycles?"

How to answer, step by step

1

Clarify the question

"Should the strings go root-first (animal -> ... -> lion) or leaf-first (lion -> ... -> animal)?"

This is the key design decision. Root-first is the natural reading order.

2

Step 1: Aggregate to a child-to-parent map

"First, I'll build a lookup map where each child maps to its parent."

const aggregate = (arr) => {
  return arr.reduce((a, b) => {
    const [child, parent] = b;
    a[child] = parent;
    return a;
  }, {});
};

// Result:
// { lion: "cat", cat: "mammal", dog: "mammal",
//   mammal: "animal", fish: "animal", shark: "fish" }
ⓘ Why aggregate first?

A child → parent map gives O(1) lookups for each node's parent. This makes the recursive traversal efficient.

3

Step 2: Recursively build the ancestry string

"For each key in the map, recursively walk up to the root and build the string."

const getKey = (obj, key) => {
  const val = obj[key];

  if (val in obj) {
    // Parent also has a parent: recurse further
    return getKey(obj, val) + " -> " + key;
  } else {
    // Reached the root: start the chain
    return val + " -> " + key;
  }
};

// getKey(map, "lion"):
//   val = "cat", "cat" is in obj → recurse
//   getKey(map, "cat"):
//     val = "mammal", "mammal" is in obj → recurse
//     getKey(map, "mammal"):
//       val = "animal", "animal" NOT in obj
//       return "animal -> mammal"
//     return "animal -> mammal -> cat"
//   return "animal -> mammal -> cat -> lion"
4

Write the full implementation

const ancestry = (arr) => {
  const aggregate = (arr) => {
    return arr.reduce((a, b) => {
      const [child, parent] = b;
      a[child] = parent;
      return a;
    }, {});
  };

  const convert = (obj) => {
    return Object.keys(obj).reduce((a, b) => {
      a.push(getKey(obj, b));
      return a;
    }, []);
  };

  const getKey = (obj, key) => {
    const val = obj[key];
    if (val in obj) {
      return getKey(obj, val) + " -> " + key;
    } else {
      return val + " -> " + key;
    }
  };

  const aggregatedMap = aggregate(arr);
  return convert(aggregatedMap);
};
Test it
const arr = [
  ["lion", "cat"], ["cat", "mammal"], ["dog", "mammal"],
  ["mammal", "animal"], ["fish", "animal"], ["shark", "fish"]
];

console.log(ancestry(arr));
// [
//   "animal -> mammal -> cat -> lion",
//   "animal -> mammal -> cat",
//   "animal -> mammal -> dog",
//   "animal -> mammal",
//   "animal -> fish",
//   "animal -> fish -> shark"
// ]
5

Close with edge cases

✓ Reverse order

To get lion -> cat -> mammal -> animal, flip the concatenation: key + " -> " + getKey(obj, val).

⚠ Cycles

If the input contains A→B and B→A, the recursion will infinite loop. In production, track visited nodes with a Set.

ⓘ Time & space complexity
  • Time: O(n) for aggregation, O(n × d) for the recursive build where d is the average chain depth.
  • Space: O(n) for the map and result array.

Key insights

  • Two-step pattern: aggregate to a map, then recurse to build strings.
  • reduce() builds the child → parent lookup in O(n).
  • Recursion walks from any child up to its root, constructing the full lineage.
  • Works for multiple ancestries — each child resolves to its own root.
  • Applicable to org charts, category hierarchies, routing trees, and dependency graphs.
  • For production, handle cycles (visited set) and orphans (no parent).

Takeaway

Converting [child, parent] pairs into readable ancestry chains is a two-step pattern: aggregate to a map, then recurse to construct full paths. This pattern pops up in org charts, category hierarchies, routing trees, and dependency graphs.
