Aggregate the Input Values in JavaScript

Given multiple input elements with dot-notation name attributes, aggregate their values into a nested object structure. This is a practical question for form handling and a lightweight polyfill for advanced form libraries.

Difficulty: ⭐⭐ Category: DOM & Form Handling Frequency: Medium #form #aggregate #reduce #nested

The question

Restate what the interviewer is really asking before you write code.

  • Read input elements from a form wrapper.
  • Use their name attributes as dot-notation paths.
  • Build a nested object where each path resolves to the input's value.
HTML Input
<form id="parent">
  <input name="a.c" value="1"/>
  <input name="a.b.d" value="2"/>
  <input name="a.b.e" value="3"/>
</form>
JS Output
{
  "a": {
    "c": "1",
    "b": { "d": "2", "e": "3" }
  }
}

3

Write the full implementation

const aggregateValues = (id) => {
  const element = document.querySelector(`#${id}`);
  const inputs = element.querySelectorAll('input[type="text"]');

  return Array.from(inputs).reduce((prev, current) => {
    const names = current.name.split(".");
    let temp = prev;

    names.forEach((name, index) => {
      if (!(name in temp)) {
        temp[name] = {};
      }

      if (index === names.length - 1) {
        temp[name] = current.value;
      }

      temp = temp[name];
    });

    return prev;
  }, {});
};

Close with edge cases

✓ Dynamic forms

This works for survey builders, JSON schema forms, and any form where input names encode structure.

ⓘ Time & space complexity
  • Time: O(n × d) where n is the number of inputs and d is the average path depth.
  • Space: O(n × d) for the nested object structure.
⚠ Overwriting keys

If two inputs share the same path (e.g., both named "a.b"), the second value overwrites the first. You'd need array support (bracket notation) to handle multiple values at the same path.

Key insights

  • Input name attributes act as paths to construct nested objects.
  • Splitting by "." allows dynamic depth handling.
  • The temp reference pattern traverses the object one level at a time.
  • Create-if-missing (if (!(name in temp))) builds the structure as we go.
  • Works seamlessly for dynamic forms like survey builders and JSON schema forms.
  • Can be extended to support arrays (e.g., a.b[0].c) and multiple input types.

Takeaway

This method is a lightweight polyfill for advanced form libraries. It turns form fields into structured objects automatically, reinforces DOM manipulation, array reduction, and object traversal, and is a practical question with real-world application in form state management.
