Filter Multidimensional Array in JavaScript

Given a multi-dimensional array, create a filter function that recursively applies a callback and returns a new array with all elements that pass the test — preserving the nested structure.

Difficulty: ⭐⭐ Category: Recursion & Arrays Frequency: Medium #multidimensional #filter #recursion #prototype

The question

Restate what the interviewer is really asking before you write code.

  • Filter a nested array recursively, keeping the nesting structure intact.
  • Non-matching elements are removed, but empty sub-arrays remain.
  • Can be implemented as a standalone function or as an Array.prototype polyfill.
Input
[[1, [2, [3, "foo",
  { a: 1, b: 2 }]], "bar"]]

filter: (e) => typeof e === "string"
Output
[[[["foo"]], "bar"]]

How the question is asked

A

Direct filter request

"Filter this nested array to keep only strings."

The key: preserve the nesting structure. Unlike flat().filter(), sub-arrays that become empty should still appear in the result.

B

Progressive complexity

"Filter 1D array." → "Now nested." → "Preserve structure." → "Add it to Array.prototype."

How to answer, step by step

1

Clarify the question

"Should I preserve the nested structure, or flatten and then filter? And should this be a standalone function or an Array.prototype extension?"

2

The recursive filter function

const filter = (arr, test) => {
  const result = [];

  for (let a of arr) {
    if (Array.isArray(a)) {
      const output = filter(a, test);
      result.push(output);
    } else {
      if (test(a)) {
        result.push(a);
      }
    }
  }

  return result;
};
ⓘ Structure preservation

When we recurse and push the result, we push the entire sub-array (even if empty). This preserves the nesting structure. If we used result.push(...output), we'd flatten instead.

3

Extend Array.prototype

Array.prototype.multiFilter = function (test) {
  const originalArray = this;

  const filter = (arr, test) => {
    const result = [];

    for (let a of arr) {
      if (Array.isArray(a)) {
        const output = filter(a, test);
        result.push(output);
      } else {
        if (test(a)) {
          result.push(a);
        }
      }
    }

    return result;
  };

  return filter(originalArray, test);
};
Test it
const arr = [[1, [2, [3, "foo", { a: 1, b: 2 }]], "bar"]];

// Filter strings
console.log(arr.multiFilter((e) => typeof e === "string"));
// [[[["foo"]], "bar"]]

// Filter numbers
console.log(arr.multiFilter((e) => typeof e === "number"));
// [[1, [2, [3]]]]
4

Close with edge cases

✓ Empty sub-arrays
// Empty sub-arrays are preserved
filter([[1, 2], [], [3]], (e) => e > 1)
// [[2], [], [3]]
⚠ Prototype pollution

Adding to Array.prototype can conflict with other libraries. In production, prefer a standalone function. Prototype extensions are fine in interviews to demonstrate knowledge.

ⓘ Time & space complexity
  • Time: O(n) where n is the total number of elements across all nesting levels.
  • Space: O(n) for the result array, plus O(d) for the call stack.

Key insights

  • Extends filtering to nested arrays while preserving structure.
  • Recursion handles arbitrary depth.
  • Non-matching elements are omitted, but nesting remains.
  • The callback is flexible: filter by type, range, regex, etc.
  • Prototype extension shows knowledge of this and method design.
  • Unlike flat().filter(), this keeps the array shape.

Takeaway

multiFilter is a recursive polyfill that behaves like filter() but for multi-dimensional arrays. It traverses deeply nested structures, applies filtering logic at all levels, and retains the nested array shape in the result.
