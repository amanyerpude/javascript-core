Filter Nested Object in JavaScript

Create a function that takes a nested object and a filter function, and returns a filtered object. The critical constraint: filtering happens in-place — no new object is created.

Difficulty: ⭐⭐⭐ Category: Recursion & Mutation Frequency: Medium #filter #nested #object #recursion #inplace

The question

Restate what the interviewer is really asking before you write code.

  • Take a nested object and a filter function.
  • Remove keys whose values fail the filter.
  • Clean up empty objects left behind after filtering.
  • Must mutate the original object (no new object creation).
Input
{ a: 1, b: { c: "Hello", d: 2,
  e: { f: { g: -4 } }, h: "World" } }
filter: (s) => typeof s === "string"
Output
{ b: { c: "Hello", h: "World" } }

How the question is asked

A

Direct filter request

"Filter this nested object to keep only strings."

The key twist: in-place mutation. Most candidates create a new object — the interviewer is testing if you catch the constraint.

B

Progressive complexity

"Filter top-level." → "Now nested." → "In-place." → "Clean up empty objects."

How to answer, step by step

1

Clarify the question

"Should the filtering happen in-place (mutate the original) or return a new object? And should empty objects be cleaned up after filtering?"

2

Explain the in-place strategy

"I'll iterate with for...in, recurse into nested objects, delete failing keys, and clean up empty objects."

// Algorithm:
// 1. Iterate all entries with for...in
// 2. If value is an object → recurse
// 3. If value is a primitive → check filter, delete if fails
// 4. After recursion, if value became {} → delete it
3

Write the full implementation

const deepFilter = (obj, filter) => {
  for (let key in obj) {
    const val = obj[key];

    if (typeof val === "object") {
      deepFilter(val, filter);
    } else {
      if (filter(val) === false) {
        delete obj[key];
      }
    }

    if (JSON.stringify(val) === "{}") {
      delete obj[key];
    }
  }
};
Test it
const obj = {
  a: 1,
  b: {
    c: "Hello World",
    d: 2,
    e: { f: { g: -4 } },
    h: "Good Night Moon",
  },
};

deepFilter(obj, (s) => typeof s === "string");
console.log(obj);
// { b: { c: "Hello World", h: "Good Night Moon" } }
4

Close with edge cases

✓ Empty object cleanup

After recursing, if a nested object becomes empty ({}), it's deleted. This prevents leaving behind empty shells like { b: {} }.

⚠ JSON.stringify for empty check

JSON.stringify(val) === "{}" works but is slow for large objects. A more efficient check would iterate Object.keys(val).length === 0.

⚠ null is typeof "object"

null has typeof "object" in JavaScript. The current code would try to recurse into null, which would throw. Add a null check: if (typeof val === "object" && val !== null).

ⓘ Time & space complexity
  • Time: O(n) where n is the total number of properties across all nesting levels.
  • Space: O(d) for the call stack where d is the maximum nesting depth.

Key insights

  • In-place mutation is the key constraint — delete removes keys from the original object.
  • Recursion handles arbitrary nesting depth.
  • Empty object cleanup prevents leaving behind empty shells after filtering.
  • The filter function is customizable — strings only, numbers > 0, non-null, etc.
  • Bottom-up cleanup — inner objects are cleaned first, then parent checks if it's empty.
  • Practical for cleaning up API responses, config objects, and form data.

Takeaway

deepFilter is a flexible recursive utility for filtering deeply nested JSON structures, cleaning up unwanted values, and ensuring the result only contains matching keys. A practical interview question that strengthens understanding of recursion, in-place mutation, and object traversal.
